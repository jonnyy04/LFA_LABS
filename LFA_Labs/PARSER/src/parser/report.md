## Theory
A parser is a crucial component in computer science and programming language design. Its primary function is to analyze a sequence of tokens (often generated by a lexer or tokenizer) and convert them into a data structure, typically an Abstract Syntax Tree (AST). This data structure reflects the grammatical structure of the source code, ensuring that it follows the syntax rules of the programming language or domain-specific language (DSL). Parsers are essential in compilers and interpreters, where they validate the correctness of input code and facilitate further processing like code optimization or execution. The process of parsing helps in identifying syntax errors early and enables the compiler or interpreter to understand and process the code. Parsers generally follow specific parsing algorithms, such as recursive descent or LL/LR parsing, depending on the complexity and design of the language.

## Token Navigation (`advance()` and `match()`)

```java
private void advance() {
    currentToken = tokenIterator.hasNext() ? tokenIterator.next() : null;
}

private void match(TokenType expectedType) {
    if (currentToken != null && currentToken.getType() == expectedType) {
        advance();
    } else {
        throw new RuntimeException("Expected " + expectedType + " but found " +
                (currentToken != null ? currentToken.getType() : "EOF"));
    }
}
```

These two methods are the backbone of the parser's ability to step through the token list safely and validate expected syntax. `advance()` moves to the next token in the stream, and if no tokens remain, sets the `currentToken` to `null`. The `match()` function ensures that the current token matches an expected type, and if it does, it moves forward. If there's a mismatch, it throws an error — effectively acting as a syntax validator. This combination ensures the parser proceeds in a controlled and predictable manner. It reduces the likelihood of syntax errors going undetected during parsing.

## AST Construction (`parse()` method)

```java
public ASTNode parse() {
    ASTNode root = new ASTNode("root");

    while (currentToken != null) {
        switch (currentToken.getType()) {
            case SIZE:
                root.addChild(parseSize());
                break;
            case BACKGROUND:
                root.addChild(parseBackground());
                break;
            // ... other shape cases
            default:
                throw new RuntimeException("Unexpected token: " + currentToken.getType());
        }
    }

    return root;
}
```

This method orchestrates the parsing process by looping through tokens and delegating responsibility to specific parse methods. It builds the root of the AST and fills it with child nodes like `size`, `background`, or various shapes. The `switch` structure helps categorize the current token and ensures the correct parser method is used. It's a centralized point that connects the input token stream with the tree representation. This is the most important method because it dictates how the entire input is processed and structured. Its simplicity and clarity make the parser easy to extend and debug.

## Example Parser Method (`parseCircle()`)

```java
private ASTNode parseCircle() {
    ASTNode node = new ASTNode("circle");
    match(TokenType.SHAPE_CIRCLE);
    match(TokenType.COLON);
    node.addChild(new ASTNode("x", currentToken.getValue()));
    match(TokenType.NUMBER);
    node.addChild(new ASTNode("y", currentToken.getValue()));
    match(TokenType.NUMBER);
    node.addChild(new ASTNode("radius", currentToken.getValue()));
    match(TokenType.NUMBER);
    return node;
}
```

This is a representative parser function for a specific shape — a circle. It shows how the parser expects a specific sequence of tokens (e.g., `circle : x y radius`) and converts them into AST child nodes. Each value is parsed and stored with an appropriate name and value. This function is tightly coupled with how the language grammar is defined and ensures shape-specific data is parsed correctly. Similar methods exist for `rect`, `line`, and `triangle`, all following this consistent pattern. The modularity makes the codebase easy to maintain and scale.

## ASTNode Data Structure

```java
class ASTNode {
    private final String name;
    private final String value;
    private final List<ASTNode> children;

    public ASTNode(String name) {
        this(name, null);
    }

    public ASTNode(String name, String value) {
        this.name = name;
        this.value = value;
        this.children = new ArrayList<>();
    }

    public void addChild(ASTNode child) {
        children.add(child);
    }

    public void print() {
        print("", true);
    }
}
```

`ASTNode` represents a node in the Abstract Syntax Tree. Each node has a name, an optional value, and potentially multiple children. The class supports both data nodes (with a value) and container nodes (with children). The ability to build and print this tree allows the parser to produce a structured and human-readable representation of the parsed input. This is crucial for later stages like interpretation, rendering, or code generation. The simplicity and flexibility of this class make it a powerful part of the parser's architecture.
